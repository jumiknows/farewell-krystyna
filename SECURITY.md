# Security and Privacy

Farewell Krystyna stores published postcard content and uploaded photos in Cloudflare D1.

The studio intentionally has no account system, so possession of the studio URL is part of the access model. Do not treat that URL as strong authentication.

## Do not commit

- Cloudflare API tokens or account credentials
- private D1 exports
- unpublished teammate messages or photos
- local environment files
- deployment secrets

## Reporting

If a problem could expose unpublished content, credentials, or database data, report it privately to the repository owner instead of posting the sensitive material publicly.

Use fictional content when reproducing bugs.
